# Contribution and submission guide

SupplyGuard AI is organized as a hackathon-ready submission repository.

## Source layout

- `src/backend` contains the Express API, domain services, deterministic risk engine, seed script, and tests.
- `src/frontend` contains the React/Vite operations dashboard.
- `docs` contains architecture, setup, demo, and QA documentation.
- `demo` contains links and screenshots for the running application.
- `presentation` is the location for the final slide deck.

## Before submitting

- Run the backend checks from `src/backend`.
- Build the frontend from `src/frontend`.
- Keep `.env` files and credentials out of Git.
- Use synthetic or anonymized data only.
- Replace the demo placeholders with the real video, live URL, screenshots, and slide deck.
