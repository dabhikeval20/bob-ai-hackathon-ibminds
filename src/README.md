# SupplyGuard source

The working application is split into:

- `backend/` - Express/Mongoose API, deterministic risk engine, synthetic seed, AI contract, and tests
- `frontend/` - React/Vite dashboard and responsive operations UI

Run commands from the repository root using the `src/backend` and `src/frontend` paths documented in [`../docs/setup-guide.md`](../docs/setup-guide.md).
